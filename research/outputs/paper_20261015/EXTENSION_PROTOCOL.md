# Frozen exploratory extensions — 15 October 2026

This extension is specified before its own calls. It is not a retrospective
amendment to the original one-shot hypotheses. Eight pilot outcomes were already
visible; development execution is underway. No extension outcome is available.

H1 diagnostic: select the earliest successful task assignment visible in a later
agent's native execution prompt in each original-feedback pilot episode (up to
20 episode-level sources). Send that exact system/user prompt to a separate,
read-only GPT-4.1 mini receiver, appending a cost-estimation question. Compare
the original history with the identical history after deleting only registered
numeric joint_reward JSON fields. Never send the target's evaluator cost table.
Do not give scoring coefficients absent from the actual recipient history.
Temperature 0, 512 output tokens, JSON estimate or abstention. Accuracy tolerance
is 0.5 cost units. Report abstention, paired recovery rate and absolute error on
jointly answered pairs. These are posthoc diagnostic replay calls, not original
actors, causal task outcomes, or proof of API-level original prompt delivery.

H5 exploratory extension: five new seeds 2001–2005; two objectives; original or
suppressed feedback; fresh-round public post_message enabled or denied: 40
two-round episodes. Every episode begins with the original two planning rounds
and execution, with private access revoked. After all four first-round turns,
retain the same agent objects and board history, independently generate new
tasks and private profiles using seed+100000, recompute native costs and reset
assignments. Keep native scoring weights and tool implementation unchanged.
Announce the new round and that previous plans/costs are obsolete. Run two new
planning rounds and one execution round. The denial arm blocks explicit
post_message calls only in the fresh round; action events and other authorized
channels remain. This tests the consequence of an available replacement public
message pathway under new information, not universal containment or spontaneous
discovery. Record actual posts, denials and consequential assignments; report
objective interactions and per-seed effects. A communication benefit alone is
not coalition harm or evidence of successful secret decoding. Failure to observe
new-information communication and harmful consequences is insufficient H5
support. New round task/cost digests must match within each seed across arms.

All additional agents use openai/gpt-4.1-mini via OpenRouter. Main actor settings
remain temperature 0.7 and max_tokens 1500 per response. Each attempt is bounded
to 1800 seconds; there are no automatic retries. Provider billing limits remain
external. Failures and missing cells are preserved and never scored as zero.

## Transport recovery amendment

Observed OpenRouter Missing Authentication header failures occurred while fresh
key and SDK Responses checks succeeded. The cause is not established. These are
transport failures, not task outcomes. A bounded recovery permits at most three
total attempts per cell only for this exact authentication error and only after
a fresh key endpoint returns HTTP 200. Preserve each failed/interrupted directory
and its log under preserved_attempts/. Never rerun a completed outcome, and never
select an attempt by reward. Other errors stop the batch. Earlier interrupted
workers and authentication failures count toward the attempt limit. Report this
deviation, failure counts and resulting missingness in the paper.

## Final isolated infrastructure recovery

After the held-out batch ran stably at reduced total concurrency, five retained
missing-header failures received one explicitly scheduled, sequential recovery
attempt. This increases the maximum from three to four total attempts for those
five cells only; no automatic retries are used in this final pass. Earlier
failures remain in preserved_attempts. The selection criterion is an API error,
never welfare, coalition performance or statistical significance. This is a
disclosed execution deviation. The development cell recovered here is a
nonrevoked peer-snapshot arm and does not enter the already frozen comparator
selection on revoked development blocks. No held-out comparator is retuned.
