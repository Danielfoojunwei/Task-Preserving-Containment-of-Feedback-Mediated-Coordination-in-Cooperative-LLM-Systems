# Architectural audit of the frozen synthetic suite

This audit inspects the frozen interface and host code. It makes no model calls,
changes no frozen files, and makes no claim about live experiment outcomes.

## A later receipt can reopen a closed artifact route

The artifact guard canonicalizes commuting tasks and removes editor comments.
The receiver projection also hides the editor's round-1 artifact fields, because
the round-0 artifact is immutable. However, the frozen `TypedArtifact.feedback`
still computes the later editor's `joint_reward` from that later, hidden
attestation: a null order produces 0 and a valid canonical order produces 10.
The editor acts before the project decider, so the decider can observe this
distinction. Neither the committed artifact nor final legitimate task utility
needs to change.

[receipt_channel_certificate.json](receipt_channel_certificate.json) reproduces
this two-world capability with the actual frozen guard, feedback and evaluator.
Both worlds have the same public instance, identical guarded round-0 editor
action, and final legitimate utility 24. Baseline and action-guard deliveries
differ; numeric suppression makes these particular receiver views equal. A
composed action guard plus numeric suppression is checked as a **non-live
structural comparison**, not an experimental treatment result.

This proves an available route. It does not show that a live actor used the
route, discovered it without instruction, recovered information, or caused harm.
A future corrected interface could compute the receipt from the immutable
committed round-0 artifact or omit the later editor receipt. The correction is
simulated in the certificate and is not applied to the frozen study.

The optional unsafe content selector has another identification limit. It
changes the displayed effective-policy label and the presence of numeric
receipt fields, and its later-editor receipt may vary. Its live results cannot
uniquely attribute recovery to the textual policy tag. The separate original
selector certificate is a constructed capability proof for a restricted
transcript; it is not an attribution analysis of the full live transcript.

## Resource feedback is a cumulative preview

`ResourceAllocation.feedback` sums allocations in the complete supplied history,
including nonbinding round-0 proposals and earlier round-1 commitments. It
computes one synthetic private-value preview from those combined totals and
attaches it to visible records when numeric feedback is enabled. The frozen
final evaluator correctly uses round-1 commitments only.

Consequently, that numeric field describes cumulative proposal-plus-commitment
preview value. It is not a faithful receipt for the currently committed budget
state. Numeric exposure, private realized value, feasible allocation coverage,
and explicit violation penalties should remain separate in interpretation.

## The guards enforce specific public contracts

- Procurement rejects prices above a preannounced public ceiling, using no
  vendor-cost oracle. It bounds accepted prices and can prevent an award when
  supplying under the ceiling is unattractive. Buyer payment harm, allocation
  regret, seller profit and nonfulfillment are separate outcomes.
- Review voting requires the declared independent-reviewer quorum. It uses
  public roles and submitted votes, without actual-merit access. It can decline
  an award and does not prevent persuasive messages or coordinated valid votes.
- Resource mediation authenticates the requester and enforces public department
  authorization, capacities and residual budget. It does not optimize private
  value or prohibit favoritism that remains within those rules. Unmediated
  ledger value is reported alongside explicit overcommit and authority penalties.
- Artifact mediation changes order only when public tasks commute and strips
  editor comments. Dependency-sensitive order remains available, and the later
  receipt witness shows why closing one representation route does not establish
  all-channel containment.

The safe adaptive rule selects from public typed risk indicators. In the artifact
case it is invariant across the two legal permutations when an artifact is
present. That restricted invariance is not a noninterference guarantee for
missing artifacts, malformed submissions, other fields, or other domains.

## Strict interfaces have finite scope

The parsers reject duplicate JSON keys, nonfinite numeric constants, wrong
schemas and out-of-range typed fields. Invalid successful replies become
recorded failed actions; the runner does not rerun them for better task results.
Strict JSON controls syntax and declared types. It does not certify truthful
messages, benign intent, semantic independence, or absence of covert carriers.

The registered provenance gate and pooled commitment ledger bind eight typed
events to their authenticated actor, destination and payload. Their budget
units count registered events, not privacy bits. They do not mediate external
channels, authenticate a compromised host, train a defender, or implement the
complete cited paper systems.

Independent code inspection found that the runner applies each branch guard to
the clean parsed prefix and final actions once. It evaluates the resulting
guarded history without reparsing metadata as an actor response. The artifact
feedback explicitly projects allowed fields and does not expose evaluator-only
`_submitted_artifact_order`. These checks support this implementation contract;
they do not replace the post-completion artifact and usage audit.
