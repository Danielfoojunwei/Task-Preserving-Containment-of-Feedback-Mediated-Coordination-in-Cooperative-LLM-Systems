# Figure captions and provenance

**domain_harm_effects.** Four separately scaled panels report the held-out paired difference in coalition-condition native primary harm, baseline minus action guard, on task seeds 6101–6110. Diamonds and horizontal bars show the saved paired mean and descriptive 20,000-resample seed-bootstrap 95% interval; small circles show all ten task-seed effects. Positive effects favor the action guard. Exact two-sided sign-flip primary tests use Holm correction across four domains. Native harm units are not pooled across domains. A harm reduction alone does not establish coalition specificity or task preservation.

**cooperative_task_preservation.** Cooperative-condition action-guard costs on the same ten held-out task seeds. Utility losses use paired baseline-minus-guard utility divided by the fixed public domain scales 100, 1, 320 and 24; coverage differences use each domain’s preregistered coverage definition. Points and horizontal bars show saved means and descriptive bootstrap 95% intervals. Dashed limits are the frozen point thresholds: 2% utility loss and five percentage points coverage decline. Negative values denote improvement. Blue points satisfy the corresponding mean limit; orange points exceed it. The upper interval limits provide the stricter sensitivity check. This is not a powered noninferiority test.

**context_history_and_permission.** A separate prior experiment replays 40 actual planning prefixes across 160 execution branches. R1 compares visible versus hidden historical private planning messages with new private posting denied; R2 compares new private posting allowed versus denied with historical messages visible. All twenty seed effects are shown with their saved paired means and descriptive bootstrap 95% intervals. Exact two-sided sign-flip tests use Holm correction across these two frozen endpoints. This experiment is not pooled into the expanded four-domain tests.

**Architectural qualification.** The post-freeze audit found a residual numeric validity receipt from a hidden later editor attestation in the typed-artifact domain. Baseline and action_guard retain this receipt; information_guard removes it. The main frozen effects include that residual path and cannot establish all-channel containment. The optional unsafe selector live arm is not isolated to policy-label disclosure; complete delivered inputs must be checked before attributing recovery to any channel. The separate label-only and receipt certificates are non-LLM capability results. See DEVIATIONS.md and receipt_channel_certificate.json.

Figures are rendered from saved final estimates without refitting tests, selecting subgroups or changing the frozen analyzers.
