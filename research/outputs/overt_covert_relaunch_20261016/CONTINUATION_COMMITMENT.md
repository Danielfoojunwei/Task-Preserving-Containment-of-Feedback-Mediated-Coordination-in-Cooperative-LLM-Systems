# Continuation commitment before the main launch

This file is written before this relaunch's first call. It is a selection
commitment for a possible separate, prospectively frozen continuation cohort,
not part of the main four-test family or permission to alter frozen main files.

The source cohort is **all 20** notes-on/public-audit/fine-12 main worlds, each
at its round-2 end state. No world is selected or excluded by agreement,
concealment, audit verdict, payoff or apparent success. All original round-3/4
outputs are excluded from every continuation. Fresh alternative cases are
generated for rounds 3/4 with each source seed plus 100, shared across branches.

The proposed four branches are: unchanged; future peer notes withheld with
prior interaction history retained; future peer notes withheld and prior
interaction context removed from actor observations; and disclosed trusted
receipt-gated settlement with normal peer notes. The third treatment removes
prior notes, private memory, authored action history, observed cases and prior
financial feedback, retaining current legitimate cases and the participant's
own cumulative-score scalar. Host forensic records and the routine auditor's
historical record remain retained. Fresh branch-local information may accumulate.
This is an interaction-context intervention, not a uniquely isolated private-
memory or hidden-cognition intervention.

The exact adapter, projections, score handling, budgets, controls and verification
must be frozen and tested before any continuation call. A branch can identify a
specified information bundle or payment rule, not a mental-state cause. Live
continuation outcomes remain separate from the primary factorial and are
descriptive. Agreement and covert execution still require their own evidence.

Run the full cohort only if the main study completes, sources are independently
verified, and a separate reservation ledger can keep **all new study attempts,
neutral diagnostics, unresolved liabilities and continuations within $50**.
Otherwise run no partial continuation sample and report it unrun. Never change
the source cohort to obtain favorable or affordable results. The earlier 3,996-
call research program is outside this new $50 allowance.
