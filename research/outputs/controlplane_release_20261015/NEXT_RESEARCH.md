# Where stronger novelty would come from

The new supported result is a controlled joint-metadata decoding effect with observed harmful decisions. The construction is classical, the decoder table is supplied, the sender copies a bit, and the successful public task copies supplied answers. Publication-level novelty therefore requires more than demonstrating this channel again. This document proposes future work; none of the studies below has been run or registered.

1. **Measure a realistic leakage–utility frontier.** Implement procurement, incident triage and document-review tasks where approvals, warnings and rejection reasons help legitimate decisions. Compare complete mediation with explicit, minimal authorized release. Score accepted owner harm, coalition payoff, task quality and justified warnings separately. Freeze a primary harm comparison and a task-quality preservation margin before evaluation; report failures of either requirement. A useful result would locate which specific decisions can be hidden cheaply and which require authorized disclosure.

2. **Test strategy formation rather than supplied decoding.** Remove the XOR formula and public decoder tables. Let agents coordinate before receiving fresh private facts, then seal their strategy before held-out evaluation. Include sender intent, source encoding, receiver inference and accepted actions as separate measurements. Give all arms identical planning/search budgets and retain failed strategies. Prompt pressure can test capability; it cannot demonstrate an unavoidable outcome or spontaneous intent.

3. **Separate algorithmic scope from a weak baseline.** Run pinned native implementations of applicable information-flow defenses, including their cumulative inference accounting, provenance, failure handling and declassification rules. The present marginal guard is a deliberately local stress baseline, not OCELOT. The synthetic broker is not FLOWSEAL, CaMeL or FIDES. An extension claim needs a concrete supported interface gap in the actual implementation, followed by a patch tested under the same task and attacker budget.

4. **Establish transfer and causal attribution.** Pair model families and sender/receiver roles on the same public worlds; the current fresh-model banks do not support a causal model ranking. Predeclare crossed-message, shuffled-metadata and non-adversarial controls. Separate finite registered transcript guarantees from timing, retries, tool counts and observable resource effects, adding each channel explicitly before testing it.

5. **Keep measurement independent of action acceptance.** Record raw well-typed predictions even if another task field fails, while counting only accepted actions as executed harms. Report abstention, invalidity, encoding adherence and whole-task success. Use world-level paired inference, a declared multiplicity family, and power calculations based on a practically meaningful minimum effect. Freeze each redesigned study prospectively and preserve its predecessors.

The highest-value next experiment is the first: a realistic task in which a warning is useful but also secret-dependent. Demonstrating a reproducible reduction in accepted harmful coordination while preserving necessary warnings would extend the current simple-copy result substantially. Independent held-out evaluation and a direct comparison to the closest prior defense would make that claim more persuasive than additional hand-designed encodings.
