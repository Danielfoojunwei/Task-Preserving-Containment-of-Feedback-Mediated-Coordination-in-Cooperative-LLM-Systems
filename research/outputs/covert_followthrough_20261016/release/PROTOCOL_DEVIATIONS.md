# Annotation failures and bounded correction

The original study code, prompts, cases, 648 behavioral calls, all 96 initial/tie annotation calls, all-NULL original seal, failed disclosure phase and global halt remain unchanged.

1. The frozen text prompt requested two prefixes but omitted an explicit round-key schema. Most reviewers supplied `prefix` while the parser required `round`, making the original seal entirely NULL. A tested post-freeze parser maps only explicit identifiers f1/f2, numeric1/2, round1/2 or rounds1/2. It does not infer missing rows by order, accept ambiguous historical r1/r2 identifiers, change quotes or alter labels. Three regression tests cover the correction. Corrected labels and seal are stored separately.
2. The frozen public-review prompt omitted the word JSON required by provider JSON-object mode. The first three concurrent requests received HTTP400; the other29 were not dispatched after the halt. No original request was retried, no actor phase resumed, and the failed records retain their full unknown-cost reservations.
3. A distinct annotation-only supplement was frozen before32 new requests, with the required JSON instruction and literal accepted-contract evidence. It exposes no actual action ledger, private memory or other reviewers' labels. All32 completed in one attempt. Combined cost including the three unknown failed-call reservations is4.6934236USD, below the original8.50 cap; aggregate45.0460136USD remains below50.

This is a disclosed release-procedure amendment, not an untouched complete preregistered semantic evaluation.
