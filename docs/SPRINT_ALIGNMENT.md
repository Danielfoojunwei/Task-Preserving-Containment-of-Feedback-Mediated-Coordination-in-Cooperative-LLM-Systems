## Earlier carrier-study question

Track 3, Collusion Carriers and Countermeasures, Q3.1 asks: “Beyond colluding directly via text, can actions, tools or side channels be the conduit for collusion?”

Our host-generated labels, receipts and rejection outcomes directly address the carrier mechanism. The focused question is whether such observations support consequential coordination after message-content controls, and whether cutting that observation path reduces harmful coordination while preserving legitimate work.

Use Track 2, Q2.3, convincing evidence of collusion, as supporting methodology: distinguish channel capacity, actual inference, accepted actions, coalition benefit and owner harm. It is not a second selected track. Keep broader scenarios in supporting material.

The Resources suggest a three-arm project: private TEXT, ACTION-only visibility, and the same actions hidden/canonicalized. Evidence requires coalition advantage to survive action-only coordination and weaken when that observation path is cut. A native Colosseum experiment is the recommended next route, not a mandatory eligibility rule. Our synthetic metadata assay is relevant prior evidence but does not yet complete that native outcome-level comparison.

## Focused next evidence

Use a pinned native Colosseum task and three matched visibility arms. The central causal comparison is ACTION-only versus the same executed source actions hidden/canonicalized for the recipient. TEXT is a live positive-control benchmark. Check the actual native coalition-advantage implementation; also retain coalition payoff, non-coalition outcomes, total welfare and legitimate task performance.

Prevent private-text history in text-free arms. Give the recipient consequential choices after signaling; a sunk irreversible cost cannot establish useful coordination. Preserve actual task execution across visible/hidden arms; if masking also changes legitimate information or feasible actions, report a bundled intervention.

Resources recommend 3–5 pilot seeds per condition and expansion to 10–20 only after a positive control works. Freeze the gate, sampling and expansion rule before inspecting results; use fresh held-out worlds and retain the pilot separately. These are practical counts, not a power guarantee. A scripted control proves opportunity, not live collusion.

Strategy formation without a supplied codebook is a useful extension after the basic visibility experiment works. Equalize search budgets and seal strategies before held-out secrets. Register all primary outcomes, invalidity handling, utility requirements and multiplicity rules prospectively.
