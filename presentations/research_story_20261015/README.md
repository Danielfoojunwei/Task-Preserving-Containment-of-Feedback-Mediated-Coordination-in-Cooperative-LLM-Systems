## Read the results in their own units

Hiding Jira history reduced regret when new posts were already denied. Public-contract enforcement reduced the resource harm endpoint, largely by avoiding penalties. A separately frozen host-masked assay showed signed decoding through joint metadata. These results are not interchangeable measures of collusion.

The original four metadata hypotheses remain unsupported. The host-masked assay supplied decoding tables and used a neutral bit-copying source. ## Rebuild and evidence

The generator uses `python-pptx`, `matplotlib` and `numpy`; rendering uses LibreOffice. Within the complete research repository, run:

```bash
XDG_CACHE_HOME=/tmp/research-deck-cache python presentations/research_story_20261015/build_deck.py
soffice -env:UserInstallation=file:///tmp/lo-research-story --headless --convert-to pdf --outdir presentations/research_story_20261015 presentations/research_story_20261015/research_story_5_slides.pptx
```

`build_deck.py` reads the frozen full-repository results, including saved per-case outcomes for crossed delivery. It makes no model calls and does not edit research outputs. `facts.json` contains the plotted/table values. PNG and SVG charts are retained in `assets/`. `BUILD_MANIFEST.json` records input hashes; `VERIFICATION.json` records final artifact checks.

The standalone download includes every project file directly linked by the claim register under `sources/project/`, as well as selected compact evidence files. Links inside those copied original reports may refer to additional full-repository artifacts. Rebuilding the complete deck requires the original repository's saved case results. Local hashes support reproducibility, not independent execution attestation.
